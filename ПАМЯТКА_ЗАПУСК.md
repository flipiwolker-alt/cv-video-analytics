# Памятка по запуску (GPU)

Короткая шпаргалка: что и в каком порядке запускать. Подробности — в [README.md](README.md).

Окружение проекта лежит на диске **E:** (`E:\cv-venv`) — там стоит PyTorch с CUDA.
Запускать всё нужно именно интерпретатором из этого окружения:
`E:\cv-venv\Scripts\python.exe`.

---

## Каждый день: просто запустить

```powershell
cd C:\Users\User\PycharmProjects\cv-video-analytics

# Визуальный интерфейс  → http://localhost:7860
E:\cv-venv\Scripts\python.exe run_ui.py

# ИЛИ REST API + Swagger → http://localhost:8000/docs
E:\cv-venv\Scripts\python.exe run_api.py
```

При старте печатается строка с устройством — должно быть `GPU (CUDA): NVIDIA GeForce RTX 5060`.
Модели грузятся из кэша `E:\cv_models` офлайн, без скачивания.

---

## Разовая настройка (уже сделано — для справки / переустановки)

**1. Создать окружение с CUDA-PyTorch на E:**

```powershell
& "C:\Users\User\AppData\Local\Programs\Python\Python314\python.exe" -m venv E:\cv-venv
$env:TMP="E:\pip-tmp"; $env:TEMP="E:\pip-tmp"; $env:PIP_CACHE_DIR="E:\pip-cache"

E:\cv-venv\Scripts\python.exe -m pip install `
    "torch==2.11.0+cu128" "torchvision==0.26.0+cu128" `
    --index-url https://download.pytorch.org/whl/cu128

E:\cv-venv\Scripts\python.exe -m pip install -r requirements.txt
```

**2. Скачать все модели ОДИН раз** (дальше анализ идёт офлайн из кэша):

```powershell
E:\cv-venv\Scripts\python.exe scripts\download_models.py
```

**3. (Опционально) LLM-слой** — контекстная классификация речи + резюме:

```powershell
# поставить Ollama один раз: https://ollama.com/download
ollama pull qwen2.5:7b
ollama pull qwen2.5vl:7b   # только если нужна vision-проверка кадров
```

Без Ollama сервис работает — LLM-слой просто отключается.

## Проверки, если что-то не так

```powershell
# GPU виден?
E:\cv-venv\Scripts\python.exe -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"

# загрузка видеокарты во время анализа
nvidia-smi
```

| Симптом | Причина / что делать |
|---|---|
| В баннере `CPU (CUDA недоступна)` | Запущен не тот Python. Используйте `E:\cv-venv\Scripts\python.exe` |
| При анализе что-то качается из сети | Не скачаны модели — выполните `scripts\download_models.py` |
| `out of memory` на `accurate` | Возьмите `balanced`, либо отключите часть каналов (`use_action=false`, `use_ocr=false`) |
| Нет LLM-резюме | Не запущена Ollama — это норм, ядро работает без неё |
